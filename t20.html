하루 한 팁 · Day 20

연수 소리 끊김 알림 (AI로 직접 만들기)

보너스 프로그램인라인 AI로 만들기

1이런 때

원격 연수를 틀어 두고 다른 일을 하다가, 소리가 끊겨 영상이 멈춘 걸 한참 뒤에야 알 때

2이렇게

  1. 인라인 AI에서 새 에이전트 → 입력창 + → 폴더 첨부하기로 빈 폴더(예: 바탕화면 소리알림 폴더)를 붙여요.
  2. 아래 프롬프트를 복사해 그대로 보내요. 평소 말하듯 써도 돼요.
  3. 만들어진 start 파일을 더블클릭 → 오른쪽 아래 상태창이 초록이면 성공. 문제가 보이면 아래 '이어서 이렇게'를 하나씩 보내요.
원격 연수 틀어놓고 다른 일 하다 보면 소리가 끊겨서 영상이 멈춘 걸 한참 뒤에야 알 때가 많아. 소리가 10초 넘게 안 나면 화면에 크게 알려주는 거 하나 만들어줘. 컴퓨터에 뭐 따로 설치하는 건 싫고, 더블클릭하면 그냥 켜졌으면 좋겠어. 평소엔 화면 오른쪽 아래에 작게 떠 있다가, 소리 끊기면 빨갛게 깜빡이고 띵 소리도 한 번 나게 해줘. 한글이나 다른 창 띄워도 안 가려졌으면 좋겠어. 소리 다시 나면 알아서 원래대로 돌아오고. 다 만들면 켜는 법이랑 끄는 법 쉽게 적어줘.

이어서 이렇게

  • 더블클릭해도 아무것도 안 떠. 왜 그런지 찾아서 고쳐줘 (한글이 깨진 경우가 많아요)
  • 켤 때 까만 창이 잠깐 떴다 사라져. 그거 안 보이게 해줘
  • 띵 소리 나자마자 바로 초록으로 바뀌어버려. 알림 소리는 소리로 치지 마
  • 유튜브 볼 때는 잠깐 꺼두고 싶어. 오른쪽 클릭하면 멈춤이랑 끄기 나오게 해줘
  • 상태창이 자꾸 엑셀을 가려. 마우스로 끌어서 옮길 수 있게 해줘
  • 실수로 두 번 켰더니 두 개가 떠. 하나만 뜨게 해줘
  • 10초 말고 20초로 바꾸고 싶으면 어디 고쳐?

덧붙임AI가 만든 프로그램은 처음 켤 때 보안 경고가 뜰 수 있어요. 내가 만든 파일이면 [실행]을 눌러요. 완성본은 위쪽 '무료 프로그램 한 번에 받기' zip의 연수소리끊김알림 폴더에 있어요.
