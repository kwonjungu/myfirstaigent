클로드 앱 준비

  1. 1

    내려받기

    claude.ai/download → Windows용 다운로드.

  2. 2

    시작하기 · 로그인

    시작하기 → Google 또는 이메일로 로그인. 코워크는 Pro 이상 계정이어야 해요.

  3. 3

    Cowork · 폴더 추가

    입력창에서 Cowork를 고르고 프로젝트 또는 폴더 → 폴더 추가로 inlineAI_실습을 골라요.

  4. 4

    수동 승인

    입력창 아래 수동 → 수동 승인. 하나씩 승인하고 넘어가요.

  5. 5

    Claude 지침

    내 이름 → 설정 → 계정 → Claude 지침에 짧은판을 붙여요.

  6. 6

    코드 실행 켜기

    설정 → 기능 → 클라우드 코드 실행 및 파일 생성을 켜요. 스킬에 필요해요.
