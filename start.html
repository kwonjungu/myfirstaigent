STEP 2 · 준비

시작 준비
AI를 내 컴퓨터에

실습 자료 받기, 설치·가입, 폴더 초대, 지시사항까지. 여기만 따라 하면 끝나요.

📦 실습 자료

실습 자료는 이것 하나만 받아요

받아서 바탕화면에 압축을 풀면 inlineAI_실습 폴더가 생겨요. 실습 01~12 파일이 모두 들어 있어요.

실습 자료 전체 내려받기 (zip · 51MB) ↓

여섯 단계면 준비 끝

  1. 1

    설치

    inline-ai.com → 위쪽 개인용 → Windows용 다운로드 → 받은 파일 두 번 클릭.
    막히면: 마우스 오른쪽 관리자 권한으로 실행 · 파란 창은 추가 정보 → 실행 · 와이파이가 느리면 핫스팟.

  2. 2

    로그인

    inline AI를 켜고 계정을 만들거나 로그인해요. 가운데 입력창이 보이면 성공. 아래 일 버튼(학교 업무 등)은 누르면 바로 실행되니 구경만.

  3. 3

    초대 코드

    초대 링크로 들어가거나 앱 위쪽 초대 이벤트에 코드 K2YERY3H. 무료 1,000 크레딧을 더 받아요.

  4. 4

    폴더는 하나만 초대

    오른쪽 위 네모(작업 패널) → 접근 가능한 폴더 → 폴더 추가… → 바탕화면 inlineAI_실습 하나만 골라요.
    다른 폴더 · 바탕화면 전체 · 다운로드 폴더는 등록하지 마세요. (그림은 강사 PC라 Desktop이 보여요)

  5. 5

    승인 모드는 확인만

    입력창 아래가 모든 편집 허용하기로 되어 있는지 확인만 해요. 그대로 둬요. 대신 폴더를 실습 폴더 하나로 막아 둬요.

  6. 6

    지시사항 붙이기

    아래 짧은판을 이 사이트에서 [복사] → 왼쪽 아래 내 이름 → 설정 → 일반 설정 → inline AI 지시사항에 Ctrl+V. 모든 대화에 적용돼요.

📋 복사 버튼

프롬프트는 이 사이트에서 복사해요

실습 페이지의 프롬프트 [복사] → inline AI 입력창에 Ctrl+V.

📋 복사해서 쓰기

지시사항 — 기본 지침 짧은판

복사해서 설정 → 일반 설정 → inline AI 지시사항에 한 번만 붙여 넣어요. 연수가 끝나면 지워도 돼요.

★ 짧은판
나는 초등학교 교사야. 학교 문서를 함께 만든다. 1. 속도가 가장 중요해. 네가 열 수 있는 건 이 실습 폴더뿐이니 허락을 묻지 말고 바로 실행해. 내가 '먼저 보여 줘', '물어봐'라고 할 때만 멈춰. 2. 필요한 파일만 열고 필요한 부분만 읽어. 폴더 전체나 긴 PDF를 끝까지 읽지 마. 3. 한 번에 고치고, 다 만든 뒤 확인은 한 번만 해. 다듬기를 되풀이하지 마. 4. 원본은 덮어쓰지 말고 새 이름으로 저장해. 5. 파일이나 내 말에 없는 사실·숫자·날짜·이름은 지어내지 말고 [확인 필요]라고 쓰고 넘어가. 6. 날짜 '2026. 3. 12.(목)', 시간 '14:30', 금액 '1,500,000원' 형식. 요일이 맞는지 확인해. 7. 열려 있는 양식의 글꼴·표·순서는 그대로 두고 내용만 채워. 8. 공문서를 쓸 때만 '00_업무지침/공문서_작성법_AI학습용.md'를 읽어. PDF는 열지 마. 9. 끝나면 바꾼 곳과 [확인 필요]를 3줄 이내로 알려 줘.

안전장치 세 가지

승인 모드는 '모든 편집 허용하기' 그대로. 대신 이 세 가지로 지켜요.

폴더 하나만

접근 가능한 폴더는 inlineAI_실습 하나. 그 밖은 AI가 못 봐요.

원본은 새 이름

지시사항에 '새 이름으로 저장'이 들어 있어요.

목록은 필요할 때만

기본은 바로 실행. 필요할 때만 '목록 먼저 보여 줘'.
