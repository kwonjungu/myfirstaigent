# 캡처 계획 (2026-10-12)

헤드리스 캡처는 가려진 창에서 멈춘다(측정 중 확인). 원칙: **한 번에 하나, 창을 앞으로, 시간 제한, 찍은 뒤 눈으로 확인.**

## A. 실습 파일 미리보기 (assets/practice/*.png) — 새 키 2개
| 키 | 원본 | 방법 |
|---|---|---|
| 02_survey | 02_엑셀_설문통계/2026 가상초 교육과정 만족도 설문(응답).xlsx | Excel → PDF(COM, 150초 제한) → 1쪽 PNG, 자동 자르기 (OLD tools/render_previews.py `to_pdf`·`pdf_pages`) |
| 10_xlsx | 09_기초학력_인포그래픽/2025 학년초 기초학력 진단활동 결과(오현초).xlsx | 같은 방법. 1쪽(초등학교 시트)만 |



- 실행: 측정이 끝난 뒤(오피스 앱을 측정기와 같이 쓰지 않기). 앱은 새로 띄우고 끝나면 그 프로세스만 닫기(사용자 한글 창 PID 보존).
- 확인: 빈 화면·잘림·원래 학교명·실제 학교 전화번호 남았는지 PNG를 열어 확인.

## B. 앱 화면 (assets/shot/inline/*) — 교안 한 줄 안내에 필요한 4장
| 장면 | 어디서 | 방법 |
|---|---|---|
| 사이드바 `한/글 편집하기`·`Excel 편집하기` | 메인 창 | CDP 스크린샷(9333), 해당 버튼 영역 강조 |
| 한/글 편집 창 + `새 에이전트` | 편집 창(/edithwp) | 한글 문서 하나 연 상태에서 `bring_to_front()` 후 CDP 스크린샷, timeout 5초 |
| `전체 수락하기 / 전체 거절하기` | 편집 창 | 측정 기록(runs/*/chat)에 나온 장면을 다시 만들기: 짧은 프롬프트 1개로 수정 후 끝 화면 |
| 선택지 카드(1·2·3·기타·건너뛰기) | 편집 창 | runs/base2/c02c/s1_0016.png 재사용 가능(계정 정보 없음) — 확인 후 사용 |

- 계정 정보 가리기: 메인 창 왼쪽 아래 계정 이름·이메일 영역을 단색으로 덮기(OLD tools/mask_shots.py 방식). 편집 창은 계정 표시 없음 — 그래도 열어서 확인.
- 크레딧: 전체 수락 장면용 프롬프트 1회(2~5 크레딧 예상).

## C. 사이트·교안 렌더 확인 (헤드리스 Edge)
- 페이지: index, start, p01, p05, p13, wrap — 1280px·390px 두 폭. 교안 PDF: 준비·실습 제목·긴 프롬프트·도전·동시에·마지막 장.
- 모든 헤드리스 호출에 `--virtual-time-budget`과 subprocess timeout. 멈추면 다시 시도하지 말고 원인부터.

## 순서
1. (지금) 사이트·교안 에이전트 작업 / 측정 계속
2. 측정 끝 → A 미리보기 4장 → 눈으로 확인
3. B 앱 화면 → 계정 가리기 → 눈으로 확인
4. 최종 빌드(레포 루트) → C 렌더 확인 → 커밋·push
