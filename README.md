# 내 첫 에이전트 AI — 학교 현장 실습

> 일단 던지고, 내 컴퓨터에 초대하고, 정해진 양식을 주세요.

초등 선생님이 실제 학교 문서로 **에이전트 AI**(inline AI)에게 일을 맡겨 보는 연수 사이트입니다.
사이트: https://kwonjungu.github.io/myfirstaigent/

## 구성 (홈에서 모두 들어가요)

1. **에이전트 AI란?** — `concept.html`
2. **시작 준비** — `start.html` (실습 자료 zip · 설치 · 가입 · 폴더 초대 · 지시사항)
3. **영역별 실습 01~12** — `p01.html` ~ `p12.html` (기본 → 보통 → 도전 순서, 단계별 가이드 · 사진 · 프롬프트)
4. **클로드 챕터** — `claude.html`, 정리 `wrap.html`
